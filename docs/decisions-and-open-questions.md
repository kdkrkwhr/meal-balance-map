# 결정과 미확인 사항

[문서 홈](../README.md) · 기준일 2026-11-09

## 사용자와 정한 방향

- 이름/저장소: `meal-balance-map`.
- 대상: 누구나 일상에서 균형 잡힌 외식을 고르는 서비스. 운동·식단 관리 사용자 한정안은 대체됨.
- 지도 중심 UX, 잇플 식당 정보와 AI 추천 활용.
- 식약처 표준DB를 영양 참고정보의 근거로 사용.
- 계산 skill, LLM Wiki와 Graphify의 근거 연결 기능 포함.
- 운영비 0원 목표와 Vercel 우선 검토.
- 현재 요청 범위는 **문서 추가**. 앱 구현·API 신청·배포는 아직 하지 않음.

## 기획서의 제안이며 아직 확정하지 않은 것

한 지역으로 시작, 설명형 평가 우선, 정적 JSON/Wiki/그래프, 로그인 없는 UX, 구체 프레임워크·지도 SDK·모델, 데이터셋 규모, 평가 기준과 검수 표본, 일정의 세부 작업일.

## 결정 변경 방식

새 정보를 얻으면 확인일·출처·결정·미해결 영향을 함께 남깁니다. 공급자 이용 조건을 추정으로 ‘완료’ 처리하지 않습니다. 무료 목표와 충돌하는 유료 구성, 데이터 공개 범위 확대, 의료 목적 기능은 사용자 결정 없이 도입하지 않습니다.
