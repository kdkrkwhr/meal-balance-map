# 운영비 0원 목표와 개인정보

[문서 홈](../README.md) · 요금·약관은 배포 시 재확인

## 0원의 정의

호스팅·지도·AI·저장소·API의 **추가 외부 서비스 청구액 월 0원**을 목표로 합니다. 개발 시간, 기존 개인 장비, 전기·통신 비용까지 0원이라는 의미가 아닙니다. 무제한 사용량과 항상 가용한 서비스를 보장하지 않습니다.

무료 한도가 소진되면 기능을 줄이거나 요청을 중단합니다. 자동 유료 전환·충전·초과 과금을 활성화하지 않습니다. 구현 전에 실제 계정의 청구 설정과 무료 차단 정책을 확인합니다.

## 배포 선택

| 안 | 장점 | 선행 조건 |
| --- | --- | --- |
| Vercel 우선 | 사용자가 선호하는 무료 배포 후보, 정적 웹 중심 구성 | Hobby 비상업 개인 이용 제한과 리워드 공모전 적합성 확인 |
| Cloudflare Pages/Workers Free | 정적 배포·경량 중계·무료 AI 후보 | 제품/모델 약관, CPU·요청·AI 한도, 잇플 접속 조건 확인 |
| 완전 정적 데모 | 사전 검수 데이터와 설명으로 외부 AI 호출 최소화 | 실시간 연동이 제한되며 대회 적격성을 대체 보장하지 않음 |

사용자가 Vercel 이용을 선호한다는 사실과 공급자가 이번 용도를 허용한다는 사실은 구분합니다. 유료 플랜만으로 해결 가능한 조건이 생기면 임의 업그레이드하지 않고 범위·대안을 결정합니다.

## 무료 한도 참고

2026-11-09 기획 조사 기준입니다. 사용 가능 계정·상품의 최신 원문을 다시 확인해야 합니다.

- Workers Free: 일 100,000 요청, 요청당 CPU 10ms 안내. Pages Functions와 사용량 관계 확인 필요.
- Workers AI: 일 10,000 neurons 무료 안내. 모델·입출력량에 따라 소비량이 달라 사용자 수로 바로 환산할 수 없습니다. 한국어 메뉴 매칭 품질은 미검증입니다.
- 지도: SDK 호출·타일·표시 의무와 계정별 무료 할당 확인. 정적 지도라고 무조건 무료가 아닙니다.
- 식약처: 허용된 다운로드 데이터의 필요한 부분을 빌드해 사용자 요청마다 API를 호출하지 않는 방안을 제안합니다.
- 잇플: 무료 제휴 안내가 있지만 이용 조건·호출 한도·IP 등록·공개 앱 이용 허가가 남아 있습니다. k-skill 프록시를 무제한 무료 백엔드로 가정하지 않습니다.

개발자의 유료 AI 구독을 공개 앱용 무료 API로 사용하지 않습니다. BYOK는 비용을 사용자에게 옮기는 방식이며, 로컬 모델도 장비·가동 비용이 있어 자동으로 0원 대안이 되지 않습니다.

## 비용 차단 설계

- 서버에서 일일 총량·이용자별 제한을 적용하고 제한 상태 자체의 일관성을 보호합니다.
- AI 입력 길이·출력 길이·재시도를 제한합니다. 공급자 무료 차단과 별개로 앱에서 여유 한도를 둡니다.
- Wiki/Graphify와 검수 설명은 빌드 시 생성합니다. 캐시·저장은 원천 허용 조건을 따릅니다.
- 지도 한도 시 목록, AI 한도 시 조건 버튼과 검수 설명, API 장애 시 명시적 오류로 전환합니다.
- 무료 서브도메인을 우선하고 이미지 업로드·과도한 로그·별도 분석 도구를 초기 범위에서 제외합니다.

## 개인정보와 입력 안전

- 초기 로그인·건강 이력 수집 없음. 질병·복약·체중 기록은 수집하지 않습니다.
- 위치는 동의를 얻어 필요한 요청에만 사용하고 불필요하게 보존하지 않습니다.
- 원래 기획서의 방침대로 자연어 원문을 외부 AI에 보내지 않습니다. 기기에서 허용된 일반 선호만 추출할 수 있어야 하며, 지원하지 못하는 입력은 전송하지 않고 조건 버튼으로 유도합니다.
- 자유 입력에서 민감정보를 완벽히 제거할 수 있다고 가정하지 않습니다. 이 처리가 검증되기 전에는 외부 AI 자연어 연동을 활성화하지 않습니다.
- 사용자 원문·정확한 위치·식별자를 로그에 남기지 않는 기본값을 둡니다. 최소 집계와 보존 정책은 구현 시 문서화합니다.
- 키·기관 인증정보는 서버 측 비밀 저장소에 두고 저장소·클라이언트에 포함하지 않습니다.
- 검색 결과·메뉴 문구·사용자 입력은 데이터이며, 도구 실행이나 권한 확장의 지시가 아닙니다.

## 최대 선행 제약

잇플 직접 API는 기관코드와 고정 IP 등록을 요구합니다. 무료 서버리스의 외부 송신 IP가 요구에 맞는지는 확인되지 않았습니다. 주최 측이 승인한 프록시나 대체 연결 방식을 확인하기 전에는 ‘0원 실서비스 연동 완료’를 목표 달성으로 표시할 수 없습니다.
