# 개발 단계와 검증 기준

[문서 홈](../README.md) · **아직 구현 전이며 아래 테스트는 계획입니다.**

## 단계별 진행

### 1. 연동 가능성·데이터 확보

- 대회 조건, 잇플 발급·고정 IP·프록시·저장/표시 허가 확인
- 무료 배포·지도·AI 후보의 실제 계정 조건 확인
- 한 지역과 검수 가능한 식당·메뉴 범위 선택
- 식약처 다운로드/API 이용 조건과 원본 필드·단위·누락값 확인
- 허가된 실제 메뉴를 확보하고 식약처 매칭 샘플 구성

완료 기준: 메뉴를 합법적으로 확보하고, 승인된 잇플 호출 경로와 0원 제약을 만족할 구성이 확인됨. 불가능하면 실제 기능을 구현했다고 주장하지 않고 시연 범위를 조정함.

### 2. 지도 MVP·계산 skill

- 지역 검색, 좌표 변환, 지도/목록, 메뉴 연결과 근거 패널
- 구조화된 영양 조회·기준량 환산·누락 처리·조건 평가
- 검수된 메뉴에 한정해 후보 비교와 잇플 상세 이동

완료 기준: 실제 데이터와 모의 데이터를 구분하며, 기준량·출처가 빠진 메뉴는 평가를 보류함.

### 3. 제출판 AI·Wiki·Graphify

- 모델 후보의 한국어 메뉴 매칭과 설명 평가
- 일반 식사 선호의 안전한 처리와 규칙 기반 대체 흐름
- 근거 Wiki와 검수된 관계 그래프, 공식 전환 추적이 확인된 경우 연동
- 호출 제한·에러·한도 소진 처리

완료 기준: AI가 데이터에 없는 숫자·재료·효능을 확정하지 않고, 근거 조회와 대체 흐름이 작동함.

### 4. 공개 전 검증·제출

- 모바일 화면, 접근성, 지도·목록·근거·상세 이동 확인
- 실제 계정의 무료 한도·청구 차단, API 저장/표시 권한 확인
- 문서·데모·제출 필드 작성, 공식 일정과 심사 방식 재확인

원 기획서는 단계별 약 1주를 제안했으나 API 승인 시점에 따라 달라집니다. 공개 모집 안내의 등록 마감 **2026-12-03**, 종료 **2026-12-13**은 공식 상세 약관 재확인 전 참고 일정입니다. 이를 확정 승인 기간이나 내부 완료 보장일로 취급하지 않습니다.

## 테스트 매트릭스

| 영역 | 확인할 사례 | 기대 결과 |
| --- | --- | --- |
| 메뉴 확보 | 실제 메뉴 없음·출처 오래됨 | 가짜 메뉴 미생성, 정보 부족 표시 |
| 매칭 | 동명 음식·다른 조리법·후보 모호 | 후보 구분, 검토 필요 또는 보류 |
| 계산 | 100g/다른 기준량·mg/g·양 불명 | 단위 검사, 근거 있는 환산만 허용 |
| 누락 | 단백질/나트륨 값 없음 | 미확인 유지, 0으로 대체 금지 |
| 설명 | 데이터에 없는 재료·영양값·효능 | 생성 차단/수정, 사실과 추정 분리 |
| 좌표 | TM128 변환·잘못된 좌표 | 검증된 위치 또는 표시 보류 |
| 검색 | 100건 제한·빈 응답·실패 | 완전한 목록이라고 오인시키지 않음 |
| 무료 운영 | AI/지도/API 한도 소진 | 유료 전환 없이 목록·버튼·오류 안내 |
| 개인정보 | 민감 자연어·위치 동의 거부 | 외부 원문 전송 없음, 지역 선택 가능 |
| 보안 | 메뉴 문구의 명령·키 노출 점검 | 실행 지시로 취급하지 않음, 비밀 미노출 |
| 근거 | 원천 버전·매칭 변경 | 화면과 Wiki/그래프가 동일 근거를 참조 |
| 전환 | 잇플 이동·중복 클릭 | 자체 지표와 공식 활성 사용자 집계 분리 |
