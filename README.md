# Meal Balance Map

**오늘의 외식, 균형 있게 고르다.**

지도에서 식당과 실제 메뉴를 찾고, 식약처 영양자료를 근거로 일상에서 균형 잡힌 외식을 선택하도록 돕는 AI 서비스입니다. 운동·식단 관리 사용자로 대상을 한정하지 않습니다.

> 현재 단계: **기획 문서 작성**. 앱 구현, 실제 API 연동, 서비스 배포는 아직 완료되지 않았습니다. 아래 구성은 개발 방향이며 무료 운영이나 공모전 적격성을 보장하지 않습니다.

## 핵심 경험

1. 지역을 선택하거나 동의한 위치를 사용해 식당을 지도에서 탐색합니다.
2. ‘채소가 있는 따뜻한 저녁’ 같은 선호로 확인된 메뉴 후보를 좁힙니다.
3. 메뉴별 영양 참고정보의 **기준량·출처·확인 수준**과 추천 이유를 비교합니다.
4. Wiki와 관계 그래프에서 근거를 확인하고 잇플 상세 페이지로 이동합니다.

## 정보와 AI의 역할

| 구성 | 역할 | 한계 |
| --- | --- | --- |
| 잇플 API | 식당 후보·주소·좌표·집계 지표·상세 링크 | 확인한 정의서에 메뉴·영양 필드 없음 |
| 실제 메뉴 자료 | 식당과 판매 메뉴 연결 | 사용 허가·최신성 검수가 필요 |
| 식약처 음식 DB | 음식코드·영양성분·함량 기준량·출처 | 해당 식당 메뉴의 실측값은 아님 |
| 계산 skill | 단위·기준량 검증, 환산, 조건 평가 | 누락값은 0으로 채우지 않음 |
| AI | 메뉴 해석·매칭 후보·추천 설명 | 근거 없는 재료·영양 수치 생성 금지 |
| LLM Wiki + Graphify | 근거 문서와 관계 탐색 | 검수된 데이터가 사실의 기준 |

## 운영비 목표

외부 서비스 추가 청구액 **월 0원**을 목표로 합니다. Vercel을 우선 검토하되 무료 플랜의 사용 적격성과 API 연결 조건을 먼저 확인합니다. 무료 한도가 소진되면 자동 유료 전환 대신 기능 제한·규칙 기반 추천으로 전환합니다. 개발 시간·장비·전기·통신 비용까지 0원이라는 뜻은 아닙니다.

## 개발 전에 풀어야 할 두 가지

- **식당별 실제 메뉴 데이터**의 확보·사용 허가·갱신 방법
- **잇플의 고정 IP 요구**를 무료 서버리스에서 충족할 승인된 연결 방법

현재 실행 명령이나 앱 테스트 명령은 없습니다. 문서에서 제안한 테스트를 이미 통과한 것으로 해석하지 마세요. API 키, 기관 인증정보, 사용자 민감정보는 저장소에 올리지 않습니다.

문서 기준일: 2026-11-09. 전달된 ‘균형 외식 지도’ 기획서 v1.0을 저장소용으로 재구성했습니다.
